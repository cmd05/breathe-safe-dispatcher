# Environmental Hacks Hackathon Summary

## Prerequisites

- Verify yourself as a student on AWS Builder Center. The PDF says every tour entry is checked against this, and student verification unlocks rewards on the profile.
- Pick one of the three environmental tracks before shaping the idea.
- To be eligible for prizes, the project must either:
  - use at least one AWS open-source tool, or
  - be deployed on AWS.
- You can build locally without an AWS account if using AWS open-source tools.
- If deploying, use the AWS Free Tier. A new AWS account can start with up to USD 200 in credits, with USD 100 available when the account is created and more earned through onboarding.
- Debit cards and RuPay are accepted for AWS account verification; the PDF mentions a verification charge of about INR 2.
- Join the WeMakeDevs Discord for team formation and help.
- Join the WeMakeDevs space on AWS Builder Center for tour updates and announcements.
- Optional: apply separately on Luma if attending the in-person build day at DTU, Delhi. The in-person day does not affect scoring.

## Tracks In Brief

### Track 01: Air

Build for cleaner air and reduced exposure on bad AQI days.

Example areas:
- AQI tracking
- Pollution exposure
- Stubble burning
- Indoor air
- School safety during bad air days

### Track 02: Heat and Water

Build for heatwaves, floods, droughts, water access, and water loss.

Example areas:
- Heatwaves
- Floods
- Monsoon waterlogging
- Droughts
- Water tankers
- Leaks
- Groundwater

### Track 03: Waste and Energy

Build for reducing waste, improving recycling, cleaner power, and better transport choices.

Example areas:
- Segregation
- Recycling
- E-waste
- Informal recyclers
- Rooftop solar
- EV nudges
- Public transport

## AWS Build Options

You can build in either mode, in any track:

- Build It: use AWS open-source tools locally.
- Ship It: deploy on AWS and submit a working URL.

Suggested AWS options from the PDF:

- Agents and AI: Strands Agents SDK, PartyRock, SageMaker AI.
- Containers and Kubernetes: Finch, EKS Distro, EKS Anywhere, EKS, ECS, Fargate.
- Serverless: SAM CLI, LocalStack, Lambda, API Gateway, Step Functions.
- Servers and runtimes: Firecracker, Corretto, EC2, Lightsail, App Runner, Amplify Hosting.
- Data and search: OpenSearch, S3, DynamoDB, RDS, Aurora.
- Auth and policy: Cedar, Cognito.
- Plumbing: CloudFront, Route 53, EventBridge, SQS, SNS, CloudWatch.

## What Needs To Be Submitted

- A working project in one selected track.
- Proof that the project either uses an AWS open-source tool or is deployed on AWS.
- A recorded demo video of up to 3 minutes. The video should show:
  - what the project does,
  - who it is for,
  - where AWS fits.
- If deployed, include the live project URL.
- If you write a blog, publish it on AWS Builder Center and link it in the submission. This is relevant for the Top 5 Blogs prize.

## Judging Criteria

- Idea and impact: the project should address a real environmental problem and clearly help the people affected by it.
- Built on AWS: AWS open-source usage or AWS service deployment is mandatory to win.
- Design and usability: the solution should be clear and usable by people outside the team.
- Execution: the project should work. One solid working feature is better than multiple unfinished ones.
- Demo video: there is no live demo, so the recorded video is what judges will evaluate.

## Prizes And Opportunities

- Top 10 students across all three tracks get fast-track interviews at Amazon.
- The top 10 students from top projects skip screening rounds for Amazon interviews.
- Each track winner gets INR 2,00,000 cash plus USD 2,000 in AWS credits.
- Top 4 runners-up across all tracks get USD 1,000 in AWS credits per team.
- Top 5 blogs win AirPods 5.
- Top teams can receive tour swag.
